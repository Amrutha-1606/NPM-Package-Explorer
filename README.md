# 📦 NPM Package Explorer

A simple web application that allows users to enter an NPM package name and view basic package information.

## Features

* Search for a package
* Simple and clean design
* Responsive interface
* Easy to use

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the project.
2. Open the project in VS Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Enter a package name and click **Search**.

## Project Files

```text
NPM-Package-Explorer/
├── index.html
├── style.css
└── script.js
```

This project is created to practice basic HTML, CSS, and JavaScript concepts.
